# 一人食 · 食材保鲜记录

纯静态食材采购记录，发布在 GitHub Pages，无后端或外部数据服务。

- 保留原有 11 项采购及 ¥135.76 实付金额，不推断未知购买日、保存方式或保质期。
- 按用户提供的商品截图补充六项保质期：鱼皮角、蒸饺和水饺为12个月，猪肉丸为5天，五花肉片和瘦肉丝为4天。保质期单独记录，不从购买日或录入日推算到期日。旧浏览器记录会补充这些信息一次，不替换已有日期、数量和用户修改。
- 记录名称、规格、实付、剩余、商店、购买日、保存方式、包装到期日、开封日、自定截止日和备注。
- 采用包装到期日和自定截止日的较早日期，按设备本地日历日倒数；日期当天显示“今天截止”，次日显示“已超1天”。
- 页面跨午夜、恢复可见、重新打开时重新计算；没有后台通知、定时云任务或食品安全鉴定功能。
- 在库、吃完和丢弃分开；吃完、丢弃仍计入采购实付，并可恢复。
- 数据仅保存在当前浏览器 localStorage（独立键 weekly-menu-food-journal-v1），不同设备和浏览器不共享。
- JSON 备份合并时，相同编号保留更新时间较新的记录；文件校验失败不会覆盖现有记录。读取损坏数据时停止写入，导出按钮保留原始数据。
- 图标为本地固定版本 Lucide 0.468.0，许可证见 LICENSE-lucide。

## 验证

- `npm ci`
- `npm test`

`core.js` 测试覆盖日历天数、闰年、跨年、缺少日期、金额、导入校验及备份合并。`app.js` 测试在隔离 DOM 和存储中覆盖录入、编辑、筛选、归档恢复、保存失败、跨午夜更新与损坏数据保护。

倒计时不是“仍可安全食用”的保证；包装说明、冷链、开封说明、实际保存情况及异常优先。个人计划截止日与包装保质期分开标注。
